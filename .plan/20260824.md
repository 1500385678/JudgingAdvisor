# 2026-08-24 增量开发计划

## 今日任务
**Phase 0 · 任务 1**:`md_to_json.py` 解析器 —— 把 `_JudgingPeopleLib/` 下的 10 个分类目录(01_人格心理学 / 02_行为观察 / ... / 10_识人经典)下的 md 转成结构化 JSON。

## 涉及文件
- 新建:`JudgingPeopleWeb/scripts/md_to_json.py`(主脚本)
- 新建:`JudgingPeopleWeb/data/rules/`(输出目录,按分类生成 `personality.json` / `behavior.json` / ... / `classic.json`)
- 源数据:`_JudgingPeopleLib/01_人格心理学/*.md` ~ `10_识人经典/*.md`

## 设计要点
1. **容错优先**:Lib 下的 md 是张勇手工笔记,无统一 schema——脚本要做到"能解析就解析,不能解析就 fallback 到 raw 段落"
2. **分类映射**:规划文档里写"性格分类 / 行为信号"是目标名,Lib 实际目录是 `01_人格心理学 / 02_行为观察 / ...`,需要在脚本里维护一份映射表
3. **输出 schema**:每个 JSON 文件至少含 `{category, source, items: [{title, content, tags}]}`,便于后续 LLM 检索
4. **幂等**:可重复运行,覆盖更新

## 验收
- [ ] 脚本可在 `JudgingPeopleWeb/` 目录下独立运行
- [ ] 至少 8 个分类目录的 md 都能被解析(01-08 为主,09-10 视情况)
- [ ] 生成的 JSON 字段齐全、UTF-8、无截断
- [ ] 末尾附 README 说明用法(`python scripts/md_to_json.py --src ../01_人格心理学 --out data/rules/personality.json`)
